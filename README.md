# OrangeHRM Web Application - Manual Testing Project

## 📌 Project Overview

This project is a Manual Software Testing portfolio based on the OrangeHRM Web Application.

The purpose of this project is to practice and demonstrate software quality assurance skills through test planning, test scenario creation, test case design, test execution, and bug reporting.

Testing focuses on verifying application functionality, input validation, error handling, and user access permissions to ensure the application behaves according to expected requirements.

## 🎯 Testing Objectives

- Verify that application features function as expected.
- Validate user input using positive and negative test scenarios.
- Identify defects and document actual results.
- Verify error messages and mandatory field validation.
- Ensure user access permissions work correctly.
- Validate CRUD (Create, Read, Update, Delete) functionality.
- Document testing activities and results.

## 🔍 Scope of Testing

The testing scope covers three main modules of the OrangeHRM Web Application.

### 1. Login Module
- Login using valid and invalid credentials.
- Validate required username and password fields.
- Verify error messages for invalid input.
- Verify login and logout functionality.
- Verify session handling.

### 2. Admin Module
- Verify User Management functionality.
- Search users using different search criteria.
- Add new users.
- Edit existing user information.
- Delete user accounts.
- Validate required fields and duplicate data.
- Verify user roles and access permissions.

### 3. PIM (Personnel Information Management)
- Search employee records.
- Add new employees.
- Edit employee information.
- Delete employee records.
- Validate required fields.
- Verify employee data persistence.
- Validate invalid and duplicate employee data.
